## 🎮 Project Description

**Awkward Eye Contact Timer 👀** is a completely useless but hilarious web game that measures how long two people can maintain eye contact.

The camera detects the players' faces and tracks their attention. The timer starts when both players are ready and stops when someone gets distracted and looks away. The winner gets a ridiculous title based on their staring time. 💀

---

## 🤡 The Problem (that doesn't exist)

People have absolutely no idea who can stare at another person longer without getting awkward.

This serious problem has affected absolutely nobody. 😭

So naturally, we decided to solve it with an entire software project.

---

## 💡 The Solution (that nobody asked for)

We use the webcam and face/eye detection to monitor two people during their staring battle.

The application:

- 👀 Detects faces
- 🧠 Checks whether both players are looking toward each other
- ⏱️ Measures the eye-contact duration
- 😭 Detects when someone gets distracted
- 🏆 Declares the winner
- 💀 Gives a completely unnecessary funny title

Basically, we turned **awkward staring into a competitive sport.**

# ▶️ How to Run

## 💻 Method 1 — Visual Studio Code

1. Download or clone this repository.
2. Open the project folder in **VS Code**.
3. Make sure these files are present:

``text
index.html
style.css
script.js

4. Install the Live Server extension in VS Code.
5. Right-click index.html.
6. Select Open with Live Server.
7. Allow webcam permission.
8. click Start Game 👀.
9. Put two people in front of the camera.
10. Stare at each other and try not to look away. 😂
