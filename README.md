# 👀 Awkward Eye Contact Timer

## Project Description

Awkward Eye Contact Timer is a fun and completely useless game that measures how long two people can maintain eye contact. The game uses the webcam and face/eye detection to detect when someone looks away and stops the timer.

## The Problem (that doesn't exist)

People have no way to determine who can maintain eye contact longer without getting awkward. This completely unnecessary problem needed a completely unnecessary solution. 😂

## The Solution (that nobody asked for)

The application uses a webcam to detect two faces and monitor their eye direction. A timer starts when both players are ready and stops when either player looks away, finally declaring the winner of the most awkward staring competition. 👀💀

## Implementation

### For Software:

#### Installation

1. Install Visual Studio Code.
2. Create a project folder.
3. Add the following files:
   - `index.html`
   - `style.css`
   - `script.js`
4. Open the project folder in VS Code.
5. Install the Live Server extension.

#### Run

1. Open `index.html` in VS Code.
2. Right-click and select **Open with Live Server**.
3. Allow camera permission when requested.
4. Click **Start Game 👀**.
5. Put two people in front of the camera.
6. Maintain eye contact and try not to look away!

## Features

- 👥 Detects two players
- 📷 Uses webcam
- 👀 Detects eye direction
- 😉 Detects blinking
- ⏱️ Measures eye-contact duration
- 💀 Stops when someone looks away
- 🏆 Gives funny ranks based on the score
- 💾 Stores best time and number of attempts
